# OpenSSH, patched for embedding

This is OpenSSH 10.2p1 vendored for [SmallCLUE](https://github.com/emkey1/smallclue)
and [iSH-AOK](https://github.com/emkey1/ish-AOK), where `ssh`, `scp`, `sftp` and
`ssh-keygen` run as **native programs**: host code compiled into the app and
dispatched from the guest's `execve`, rather than emulated guest binaries.

## What is patched

About 176 lines across 20 files, on top of `V_10_2_P1`. Three kinds:

**One binary, four programs.** Each client's `main()` becomes
`pscal_openssh_<prog>_main()` so `ssh`, `scp`, `sftp` and `ssh-keygen` can link
alongside SmallCLUE's own `main()`. The launcher that calls them — and that
wraps OpenSSH's `fatal()` and `exit()` in `setjmp`/`longjmp`, because a native
program must not take the whole app down — lives in SmallCLUE at
`src/openssh_app.c`.

**Statics that can no longer be static.** `scp.c`, `sftp.c` and
`sftp-client.c` each carried their own `interrupted` and `showprogress`. With
all three in one binary those become shared globals, so a `^C` during a
transfer reaches whichever transfer is actually running. `scp.c`'s
`cleanup_exit` is renamed for the same reason: `clientloop.c` supplies the one
the whole binary uses.

**Portability for a host that is neither Linux nor stock macOS.** Guards around
`<util.h>` in `sshpty.c`, and small changes in `openbsd-compat/` (`getopt.h`,
`readpassphrase.h`, `getopt_long.c`) so the vendored compat layer coexists with
the libc surface iSH-AOK's shim presents. `pscal_runtime_hooks.h` is new and
declares the exit/progress hooks the launcher implements.

## Why `config.h` is committed

Upstream's `.gitignore` excludes it, and normally that is right. Here the
consumer is a meson build that compiles these sources directly and never runs
`make`, so a checkout without `config.h` cannot build at all. The committed one
is for `aarch64-apple-darwin`, generated by:

    ./configure --without-openssl --without-zlib

Re-run that to retarget. `config.log`, `config.status` and the generated
`Makefile`s stay ignored — nothing here uses them.

## No OpenSSL, no zlib

Deliberate: it means **ed25519 and chacha20-poly1305 only**, and no compression.
RSA and ECDSA keys will not work. In exchange the whole client links into
iSH-AOK with no new libraries at all — 168 objects with zero OpenSSL and zero
zlib symbol references, needing only `-lresolv`.
